# Contributing to Music Puzzle Game 🎵🧩

## Project Ethos

Our mission is to create an innovative educational gaming experience that bridges the gap between music theory, emotional intelligence, and interactive learning. We believe in:

- **Accessibility**: Making music education engaging and accessible to everyone
- **Innovation**: Pushing the boundaries of what's possible in educational gaming
- **Community**: Building a supportive and collaborative development environment
- **Open Source**: Sharing knowledge and tools to benefit the broader community
- **Quality**: Maintaining high standards in both code and user experience

## Getting Started

### Prerequisites

- Rust 1.70+ with `wasm32-unknown-unknown` target
- Node.js 18+
- Git
- Basic understanding of music theory (helpful but not required)

### Development Setup

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/music-puzzle-game.git
   cd music-puzzle-game
   ```
3. Install dependencies:
   ```bash
   npm install
   cd puzzle-web
   npm install
   ```
4. Build the project:
   ```bash
   npm run build:wasm
   ```

## Code Standards

### Rust
- Follow the [Rust Style Guide](https://doc.rust-lang.org/1.0.0/style/style/naming/README.html)
- Use `cargo fmt` for formatting
- Run `cargo clippy` before submitting PRs
- Write tests for new functionality

### TypeScript/React
- Follow [Airbnb React Style Guide](https://github.com/airbnb/javascript/tree/master/react)
- Use TypeScript strict mode
- Write unit tests with Jest
- Use ESLint and Prettier

### Git Workflow
1. Create a new branch for each feature/fix
2. Use descriptive commit messages
3. Keep commits focused and atomic
4. Rebase on main before submitting PRs

## Pull Request Process

1. Update documentation for any new features
2. Add tests for new functionality
3. Ensure all tests pass
